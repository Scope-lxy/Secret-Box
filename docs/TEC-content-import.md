# 内容新增与批量导入

本文是管理后台内容新增、批量导入和素材上传的实现、接口与验收速查。产品规则见[后台 PRD](PRD-轻读手记后台.md)，图片派生、复用与回退见[图片规范](PRD-图片资产与封面处理规范.md)。

## 文档职责

- [文章文档批量导入规范](PRD-文章文档批量导入.md)是 MD 格式、容量、去重、图片处理和运营交互的产品规则真源。
- 本文记录普通内容、公众号 URL 和文章文档导入共用的实现、接口、素材处理和验收方式。
- 后台页面布局与交互视觉以[后台设计规范](TEC-admin-workbench-design-spec.md)为准；文章文档导入的文件格式和操作边界不在本文重复维护。

文章文档入口支持 MD / Markdown / TXT，文件夹会穿透子目录；文件分组上传后，服务端解析字段、去重并准备图片，复用文章预览及编辑器。正常项可先确认，剩余草稿保留 24 小时并支持主动继续。文档正文不重新清理，图片失败不静默删除，简单 Markdown 表格在后台和小程序中保留结构；公众号 URL 抓取流程和限制独立保留。

## 入口与流程

- 在内容池的任一内容卡片点击“批量导入”，会直接打开“导入内容”页面并预选对应类型。
- 侧栏“导入内容”可直接进入同一页面；先选择内容类型，再选择文件或文件夹。
- 所有类型的文件入口支持选择或拖入上级文件夹，自动穿透子目录并按当前类型筛选。文案 / 心笺识别 TXT，音频识别 MP3 / M4A，图册识别图片；跳过隐藏辅助目录和无关文件并显示数量。文案、心笺及音频的直接文件选择为辅助入口，文件夹选择为主入口。
- 浅暖色拖入区整块可点击选择文件夹，并支持 Enter / Space、悬停和键盘聚焦反馈；与右上角按钮共用选择逻辑及处理锁定。空状态仅保留操作与格式 / 子目录提示，标题下简述必要规则，读取后显示实际进度或结果。
- 多份 TXT 按相对路径排序，每份分别解码和按当前分段方式解析后汇总，自动模式逐文件判断；读取失败显示带相对路径的问题项，不能悄悄丢失文件。切换分段方式和内容池时仍按独立文件重新解析；同名文件不覆盖。选择或拖入目录的读取期间锁定来源、类型和确认，旧异步结果不得覆盖新来源。
- 各类型共用首张输入卡片布局，高度为 300px；主操作放在标题栏右上角，文章模板下载作为说明中的同字号主题色文字入口。链接文本框、目录拖入区和普通导入状态区填满剩余空间；超出内容在内部滚动，进度、恢复或重试操作不得撑高卡片。链接文本框由容器控制高度，不参与通用文本框的两行自动缩放。
- 文章既可从“文章管理”中的“批量导入”进入，也可在“导入内容”页选择“文章”；两个入口默认使用“文件导入”，在输入卡片的“导入方式”下拉框中可切换为“链接导入”。以下描述链接抓取模式：每次进入都从空白链接和空白预览开始，不恢复上次链接或任务；本轮任务及其移除、编辑状态只在当前打开的导入页面内保留。文章导入页分为上下两个卡片：上方粘贴链接，标题栏右侧点击“立即抓取”（任务完成后显示“重新抓取”）；下方标题栏左侧显示“已抓取 N 篇”（处理中显示 N/总数），右侧绿色显示“M 篇可导入”并提供“确认导入”，失败/重复数量作为辅助信息显示。每行粘贴一个公众号文章链接；提交后立即创建异步任务，后台逐条抓取并持续保存进度。抓取完成后以固定宽度、随可用空间增加列数的手机比例窗口逐篇查看统一阅读模式和自动清理结果，不再在手机窗口外重复显示状态和 URL。必要时可恢复被识别的尾部，或使用右下角圆形按钮编辑、移除当前条目；失败窗口还可单独重新抓取该 URL，重试沿用当前批次，不会覆盖其他成功文章或管理员尚未确认导入的编辑内容。
- 每次重新选择文件或文件夹，都会替换当前整批预览，不会追加到旧预览。
- 解析后先在预览中检查和修改内容，再点击“确认导入”。有错误的条目不能提交。
- 每批最多导入 200 条内容；超过时请分批选择来源。
- 确认期间会锁定类型切换、文件选择、预览编辑和返回操作。上传失败的图片可以单独重试或从预览条目移除。
- 批量导入成功或失败只在当前导入页提示结果，不自动切换到内容管理，也不主动刷新内容列表；普通内容重新选择下一批文件即可继续，公众号文章发布成功后会清空当前链接和预览并继续停留在文章导入面板。

“新增”用于创建单条内容；它与批量导入都只追加新内容，不会保存或覆盖当前编辑器内无关的数据。文章新增、已发布文章编辑和导入草稿编辑复用同一个双栏弹窗：左侧编辑两行标题与 Markdown 正文，右侧修改封面和发布时间并实时查看阅读卡片。文章封面上传仅接受 JPG/JPEG、PNG、WebP；GIF 不可作为封面。标签默认值为“默认”，仅用于后台分类，小程序端不显示。

## 导入格式

| 内容类型 | 选择来源 | 解析规则 | 图片规则 |
|---|---|---|---|
| 私密文案 | TXT 文件夹或直接选择 TXT | 各文件分别用空行、序号或 `---` 分隔多条文案，再合并预览 | 无 |
| 私密音频 | 音频文件夹或多个 MP3/M4A 文件 | 每个文件独立成为一条音频，不要求填写标题 | 无 |
| 心笺 | TXT 文件夹或直接选择 TXT | 各文件分别用空行、序号或 `---` 分隔多条内容，再合并预览 | 无 |
| 私密图册 | 一个图片文件夹 | 可识别不同子目录内的图片，或用相同名称加序号作为分组标识；未分组的单张图片各自成为一个图册 | 每组保留前 1–9 张 |
| 文章 | 文章文件夹或每行一个公众号 URL | 文件模式按[文档导入规范](PRD-文章文档批量导入.md)逐篇读取 MD / Markdown / TXT；链接模式仅支持 `mp.weixin.qq.com`，自动提取为 Markdown 阅读模式 | 文件与链接模式中的远程图片均经受控下载转存 COS；手工编辑时选择本地封面会直传 COS |

私密图册和普通图片支持 JPG、JPEG、PNG、WebP、GIF，单张不得超过 5MB；文章编辑弹窗上传的封面仅支持 JPG、JPEG、PNG、WebP。超过每组图片数量上限时，按文件名排序保留前面的图片，不作为导入错误。

音频仅支持 MP3、M4A，单文件不得超过 50MB。浏览器选择文件后保留原始文件名；文件先上传到服务端临时目录，经 FFmpeg 根据每条音频自身的响度自适应标准化后写入 COS。处理成功、失败或中断后都会删除服务器临时文件；COS 只保留标准化后的播放文件。服务端在确认时保存原始文件名、对象 key、MIME 类型、处理后大小、时长和 `audioUrl`。小程序标题默认使用去除最后一个扩展名后的原始文件名，运营无需逐条填写标题。

内容管理的音频表提供“试听”入口。点击后在当前后台页面右下角显示悬浮播放器，沿用小程序完整音频卡片的视觉结构并缩小适配后台；支持播放/暂停、重播回到开头、拖动进度和时间显示，不提供循环、音量等高级功能。页面只维护一个播放器，初始不加载音频，首次点击时才使用 `Audio` 的 `preload="none"` 懒加载当前 `audioUrl`；切换另一条、刷新分页或删除当前条目会停止上一条播放。

TXT 优先按 UTF-8 读取，并兼容常见旧版中文 TXT 编码。当前导入不使用 Excel、粘贴表格或 ZIP。

目录读取统一使用 `folder-import-files.js`，供普通导入和文章文档导入复用：在拖入事件内立即取得目录入口，递归读完每次至多 100 项的全部分页，保留完整相对路径并跳过辅助目录。各入口分别校验文件类型和原有数量 / 大小限制，文章的 200 份 / 1MB / 20MB 限制不套用到音频和图册。音频元数据最多同时读取 4 份，超时释放本地资源，避免大量文件同时创建播放器或个别文件阻塞整批。

## 预览与确认

- 绿色数量只在存在可导入条目时显示；有异常时单独显示需处理数量。
- 私密图册可修改标签，文本类可修改内容；公众号文章抓取成功后，预览卡片固定为约 314px 宽，随可用空间增加列数，阅读窗口保持接近小程序手机页面的纵横比；宽屏不放大卡片和文字，正文固定使用后台普通阅读字号。卡片正文区域仅允许纵向滚动，正文图片始终铺满内容宽度且不会撑宽卡片；正文基础间距为 `10px`，连续图片或媒体内部间距为 `12px`，两套参数独立控制以便单独微调。成功文章默认保留并随本轮确认导入，不设置复选框或单篇确认步骤。卡片右下角由上到下显示删除、编辑两个圆形按钮；编辑按钮打开与文章管理共用的双栏弹窗，可同时修改标题、Markdown 正文、封面和原始发布时间，右侧阅读卡片实时预览当前草稿。标题、封面和时间立即同步，正文停止输入约 300ms 后经服务端安全渲染更新；“保存”只更新本次导入草稿，最终仍需点击“确认导入”。关闭存在未保存修改的弹窗时必须确认放弃。删除按钮不弹确认，只从当前批次预览移除该条目，失败和重复条目也可直接移除，不影响已正式发布内容。系统识别到推广尾部时，会显示清理摘要和“恢复已移除文字”；恢复时按原文顺序放回文字，尾部图片不会恢复。完成整理后，点击导入预览卡片右上角“确认导入”，一次性把仍保留的全部成功文章写入内容池；全部成功文章被移除后，按钮自动隐藏且不能导入。
- 预览中的移除只影响本次导入批次。
- “确认导入”旁不拼接数量，数量独立显示。导入完成后，同一批次再次提交不会因重试重复追加相同 ID 的内容。

## 去重与素材复用

- 私密文案和心笺会先把正文首尾空白移除，并把连续空白折叠为一个空格，再直接比较正文；同一批次或当前内容池中已有相同正文时会跳过。
- 文章优先按后台从来源 URL 计算的规范身份去重，兼容历史来源哈希；文档另保存图片转存前的导入指纹。无明确来源但内容相同可去重，只有标题或文本对应时进入疑似重复确认。解析后和写入前分别检查同批及目标内容池，文件改名和网络重试不会重复追加。
- 私密图册不做内容项级去重；即使图片排列相同，只要内容 ID 不同，仍可分别导入。
- 批量上传、导入预检和文章抓取按原始文件字节的 SHA-256 与 `processingProfile` 共同识别素材。两者都相同才可复用素材 ID；同批相同图片只上传一次，并让各内容项引用同一素材。处理标记不同的图片不得互相复用派生图。后台单张上传当前不计算 SHA-256，因此不承诺跨历史去重。
- 音频不新增按文件内容的去重规则，继续使用现有内容 ID 和上传任务 ID 保证失败重试不会重复追加。

## 公众号链接抓取边界

- 导入请求立即返回 `202` 和任务 ID，服务端逐条抓取并把进度写入 `article_import_jobs`；Admin 轮询状态。服务重启导致任务中断时，任务标记失败并要求重新创建，不伪装为继续执行。
- `author` 优先保存蓝色的公众号账号名称：先读取页面账号节点（如 `#js_name`、`.profile_nickname`），再读取脚本 `nickname` / `profile_nickname`；这些来源均为空时，才使用 `meta author` / `article:author`、可见作者署名或脚本 `author` 兜底。两者均缺失时保留空值，须在预览编辑中补充后才能确认导入；预览和保存沿用同一字段，手动编辑值优先。
- 页面 URL 只允许 `mp.weixin.qq.com`；正文图片允许来自任意公网图片主机，不再依赖微信图片域名白名单。图片请求仍会逐次校验协议、账号信息、标准端口、重定向和 DNS 解析结果；内网、回环、链路本地、组播等非公网地址一律拒绝，避免 SSRF 和 DNS 重绑定。
- 页面上限 8MB，单张图片上限 5MB，并校验超时、HTTP 状态、MIME 与图片文件魔数。公众号 `section/div` 会先还原为标题、段落、引用、列表、图片等语义块，再转换为统一 Markdown；字体、颜色、对齐、视频、卡片、脚本、样式和事件处理器不进入正文。网页表格不承诺还原；文档中的简单 Markdown 表格由文档入口单独支持。
- 自动清理只扫描正文最后 35% 且最多 60 个语义块。独立的推荐栏目标题、明确的点赞/在看/星标/留言/扫码关注指令、投稿商务联系方式、公众号内链密度等构成强信号；单个普通关键词、外部参考链接、路线/海拔/开支等正文数据不会触发。检测到连续正文恢复，或清理后不足 2 个正文块和 80 字时，会放弃自动删除。作者/编辑署名、来源、免责声明、版权和风险提示属于受保护内容，不会因为前面出现互动引导而连带删除；若同一段后半截附带投稿或商务联系方式，只移除联系后缀。
- 同一批文章完成抓取后，会额外检查每篇开头或结尾的边界语义块；只有带推广/互动/链接列表信号、且至少 3 篇相同的片段，才会作为“批次重复模板”移除。短文、只有 1–2 篇出现的片段和正文主题重复不会触发；移除内容仍可在预览中恢复，恢复时按原始正文顺序放回，批次移除的图片与尾部图片一样不恢复，只保留文字。
- 发布时间优先读取公众号页面的 `article:published_time`、`publish_time`、`create_time`、`ori_create_time`、`ct` 等字段（支持日期文本及 Unix 秒/毫秒时间戳），也读取页面可见发布时间。无法识别有效原始发布时间时，该篇标记为失败且不能确认导入，不使用抓取或导入时刻冒充原始发布时间。
- 正文图片按 SHA-256 转存到项目 COS 的文章目录，正文改写为项目 HTTPS 地址；封面按“哈希 + 处理标记”复用或登记图片素材。普通静态正文图和文章封面使用 `display-v1`，GIF/动画图以及高度超过宽度 3 倍的正文长图使用 `original-only`；文章封面绝不按文章大卡的 `2.35:1` 容器比例裁切。完整图片规格见[图片规范](PRD-图片资产与封面处理规范.md)。最长边不超过 96px 的静态小图继续过滤；仅正文首尾连续边界块中的极端横幅/竖条图片会按比例过滤，图片所在块允许带不超过 40 字的短标题或署名（短边不超过 160px、长边至少 400px、宽高比至少 5:1）。边界还支持“推荐阅读/往期/更多/相关阅读”等营销语义短标题与极端比例图片交错排列的推荐卡片，标题在图片前后均可、连续多组会成对移除；中间图片、普通图注或带较长正文的图片块不按比例过滤。单张正文图片转存失败时只移除该图片并显示警告，封面转存失败时文章继续导入但不显示封面。被自动清理的尾部图片不上传 COS，管理员恢复文字时按原始交错顺序恢复，图片仍不恢复。整篇文章抓取或正文转换失败才会将该条标记失败，不影响同批其他文章。
- `bodyMarkdown` 是文章正文的唯一保存字段。服务端按需将 Markdown 派生为安全 HTML，小程序再次清理后交给 `rich-text` 展示；HTTPS 链接保留，非 HTTPS 或危险协议不带跳转地址。不保存并行的 `bodyHtml` 或 `previewHtml`。后台编辑器支持标题、段落、加粗、斜体、删除线、引用、列表、链接、图片、分隔线、行内代码和围栏代码，不支持自定义 HTML。
- Admin 不在浏览器会话中保存或恢复链接抓取任务 ID；退出链接抓取页后再次进入，链接和预览均为空白。当前页面内查询失败时，“重试查询”继续查询本轮任务，不会重复创建。任务发布成功后立即删除，未发布的失败或中断任务最长保留 24 小时。服务启动时先清理一次，之后每小时主动清理，不依赖管理员再次访问。
- 导入正文图继续使用现有 `image_assets` 记录生命周期，文章仅额外保存 `bodyImageAssetIds` 引用元数据，正文内容仍只有 `bodyMarkdown` 一个真源。确认导入时从当前预览移除或重复的条目、过期任务、文章删除以及正文编辑后移除的图片都会进入现有 COS 回收流程；其他文章或尚未结束的导入任务仍引用同一对象时不会误删。COS 删除失败时保留素材登记，后续定时清理可重试。
- 本功能不授予转载许可。运营只能导入自有版权或已获授权内容，并负责保留必要署名、出处和来源 URL；不得用本工具绕过公众号访问控制或批量搬运无授权内容。

## 文章文档操作与接口

进入“导入内容 → 文章”，默认“文件导入”，选择目标内容池后点击“选择文件夹”。文件选择器会读取账号目录和更深层目录的文章；也可拖入目录；页面不提供单独选择文档文件的按钮。单篇或少量文章可切换“链接导入”。只读取 `.md` / `.markdown` / `.txt`，跳过数量在本批汇总中保留，重开任务仍可查看。

最多 200 份、每份 1MB、原始文件合计 20MB；超过任一限制整批明确报错，不截断。前端同时按 20 份及 2MB 原始字节分组，Base64 后发送 JSON，避免单请求过大。目录同名文件用相对路径区分，路径只作清单标识，不写成服务端文件路径。

服务端逐篇解析可读文章头、精简原文链接尾部及兼容资料，标题 / 账号 / 原始时间 / 正文缺失只阻止对应文章。时间统一按北京时间处理；普通 TXT 可回退 GB18030。图片通过既有受控请求和 COS 派生链路处理，不调用 AI、不再次删除推广段或按尺寸过滤图片。

预览每页 18 篇，卡片约 314px 宽，按可用空间自动增加列数，可按问题状态筛选、搜索标题 / 账号 / 文件名，在原有文章编辑器修改；一组缺账号的文档可批量补账号。图片失败保留占位和原因，支持单图重试、本地替换或移除。按钮始终显示本次将导入的全部正常文章数，分页和筛选不缩小确认范围。

上传清单通过 `requestId` 幂等创建，分组文件按字节哈希校验重复上传；编辑使用 `revision` 防止覆盖过时草稿。内容插入与条目完成记录在同一 SQLite 事务保存，重试确认只处理剩余正常文章。目标内容池和小程序在每次接口请求中校验，URL 任务不能通过文档接口操作，反之亦然。

离开再进入保持空白，主动点击“继续未完成导入”恢复 24 小时内草稿。服务重启将未完成准备标为可继续，查询不会延长保留期。完成后清空临时正文并保留结果回执；过期任务与无引用的远程图、本地替换图由现有定时回收处理。

## 上传实现要点

- 普通本地图片和文章编辑弹窗的手工封面由浏览器直传 COS，服务端负责签名、请求 COS 生成派生图、确认可读后登记素材和保存内容引用；每组最多 3 路并发，底层按每组最多 100 张依次准备和登记。公众号文章的正文图和封面则由服务端先从来源地址校验、下载，再转存到 COS。
- 单条新增和批量导入都会校验图片素材是否已登记；批量导入与文章抓取按 SHA-256 加 `processingProfile` 复用，单张上传不做哈希去重。
- 批量内容 ID 在预览时固定，单条新增也沿用已成功上传的素材；网络中断重试不会重复追加内容。
- 音频按顺序经服务端 FFmpeg 处理后写入 COS，不参与图片处理；上传完成即可加入内容池，是否投放由小程序的“允许音频”开关控制。
