# 轻读手记后台设计规范

本文档是当前后台面板 `/admin/` 的设计基准，维护视觉、布局和交互边界；产品功能以当前实现和测试为准。

## 一句话原则

后台不是展示页，而是运营工作台。用户进入后应先看见状态、风险和可操作入口，再进入内容、留言、安全、小程序配置等任务。

后台围绕「当前小程序」和「内容池」组织工作流；页面内保存按钮贴近当前区块，编辑类弹窗的操作统一放在右上角，危险操作必须有确认或明确状态反馈。

## 全局骨架

- 桌面端使用左侧深色导航 + 右侧工作区。
- 后台最小宽度为 `1200px`，只面向桌面运营环境，不做移动端适配。
- 侧栏宽度控制在 120px 左右，导航项保持短标题，避免换行。
- 顶部栏高度 56px，显示当前位置、账号入口和退出入口。
- 主内容区默认内边距为 `24px 28px`。

## 色彩系统

- 主操作：`#9A613B`，hover 使用 `#7B4423`。
- 主操作浅底：`#FAEEE6` / `#FFF8F4`，用于选中态、提示和 hover。
- 页面背景：`#F0F0F0`。
- 卡片背景：`#FFFFFF`。
- 二级内容底：`#F7F7F7`。
- 正文：`#191919`。
- 次级文字：`#888888`。
- 边框：`#E5E5E5`。
- 危险：`#FA5151`。
- 警告：`#FFC300`。
- 信息：`#10AEFF`。

新增颜色必须能归入主操作、危险、警告、信息、文本、边框、背景、禁用之一。

## 层级和密度

- L1 页面：页面标题、说明、首个关键状态区。
- L2 区块：`.panel`，白底、8px 圆角、轻边框、轻阴影。
- L3 内容项：表格行、编辑项、留言项、配置项，使用浅灰底或白底加细边框。
- 卡片内边距优先使用 20px/24px；二级项使用 12px/14px。
- 同组元素优先用 `gap` 控制间距，不用多个子元素 margin 叠加。

## 操作逻辑

- 当前页面直接相关的操作放在区块头右侧。
- 跨页面导航只放侧栏，不在页面中堆重复入口。
- 保存、导入、新增是主动作或浅主动作；删除、归档、拦截是危险动作。
- 导入入口和流程统一见 `content-import.md`；本文只约束入口位置、操作反馈和视觉呈现。
- 空状态、加载失败、保存成功都在当前区块附近反馈，避免只依赖全局 toast。
- 长表格保留横向滚动，不能挤压到字段不可读。
- 音频内容表的“试听”使用操作列同款裸文字按钮；点击后在页面右下角出现悬浮播放器，不打开独立页面或普通模态弹窗。
- 悬浮播放器沿用小程序完整音频卡片的结构和暖色视觉，但按后台密度缩小；只保留播放/暂停、重播、进度拖动、当前/剩余/总时长，不增加循环、音量等高级控件。
- 悬浮播放器只允许一个实例同时播放；首次点击才创建并加载音频，内容表初始化时不得预加载音频文件。

## 弹窗

- 新增、编辑和上传等编辑类弹窗不设置底部操作栏。标题与操作位于同一顶部行，右上角固定为左“取消”、右主操作，主操作按业务显示“保存”“创建”或“上传”。
- 删除、清空等危险确认弹窗保留底部确认区，让用户先读完风险再决定；该规则不与编辑类弹窗混用。

## 文章阅读与编辑视觉

- 文章预览固定为三列等宽布局，铺满内容区。卡片保持接近小程序手机页面的纵横比，正文区域独立纵向滚动，正文图片铺满内容宽度。
- 新增文章、已发布文章编辑和导入草稿编辑复用同一套 `900px` 双栏弹窗。左右比例为 `6:4`：左侧编辑两行标题和 Markdown 正文，右侧编辑封面、发布时间并实时展示独立滚动的阅读卡片。
- 后台阅读卡片固定模拟小程序普通字号：正文 `16px`、行高 `1.7`；正文基础间距为 `10px`，连续图片或媒体内部间距为 `12px`。两套间距使用独立 CSS 变量（`--article-reading-content-gap`、`--article-reading-media-gap`），即使默认值接近也必须保留分别调整的能力。
- 小程序正文使用对应的独立间距基线：正文基础间距为普通/较大/最大字号 `20/24/28rpx`，连续图片或媒体内部间距为 `24/28/32rpx`；后台预览不随字号模式切换，始终使用上述固定普通字号参数。
- 文章弹窗同样遵守编辑类弹窗顶部操作规则；存在未保存修改时关闭会转入保留底部确认区的危险确认弹窗。封面上传和删除使用封面右上角的同风格图标按钮，不额外占用纵向操作栏。

## 表单与表格

- 输入框高度 36px，按钮高度 34px 起。
- focus 统一为暖棕橙边框 + 轻色光晕。
- 标签使用 12px/700，正文输入使用 13px。
- 表格表头使用浅灰底和 12px 高权重文字。
- 可变长字段允许伸缩；状态、按钮、数字、ID 保持紧凑固定宽。
- “手记打开前引导文案”使用每行一条的多行文本框；字段校验和内容规则以后台 PRD 为准。

## 固定桌面布局

- 页面和主框架保持至少 `1200px` 宽；低于该宽度时允许浏览器产生横向滚动，不切换为移动端布局。
- 不使用视口宽度缩放字体。表格、卡片和弹窗通过固定轨道、受控换行和内部滚动保持可读性。

## 当前入口

- 后续开发统一使用 `/admin/` 和 `/admin/index.html`。
- 当前后台页面是 `index.html`，当前后台样式是 `styles.css`。
- 批量导入页面逻辑位于 `import.js`，不在 `main.js` 内维护第二套导入流程。
- `shell.js` 只承载后台外壳的轻量交互，不代表另一套后台版本。
