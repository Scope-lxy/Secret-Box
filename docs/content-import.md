# 内容新增与批量导入

本文是管理后台内容新增、批量导入和素材上传的操作/接口速查，规则以当前服务端接口和管理后台实现为准。

## 入口与流程

- 在内容池的任一内容卡片点击“批量导入”，会直接打开“导入内容”页面并预选对应类型。
- 侧栏“导入内容”可直接进入同一页面；先选择内容类型，再选择文件或文件夹。
- 文章既可从“文章管理”中的“批量导入”进入，也可在“导入内容”页选择“文章”；两个入口复用同一个公众号 URL 面板。每次进入文章导入页都从空白链接和空白预览开始，不恢复上次链接或任务；本轮任务及其移除、编辑状态只在当前打开的导入页面内保留。文章导入页分为上下两个卡片：上方粘贴链接，标题栏右侧点击“立即抓取”（任务完成后显示“重新抓取”）；下方标题栏左侧显示“已抓取 N 篇”（处理中显示 N/总数），右侧绿色显示“M 篇可导入”并提供“确认导入”，失败/重复数量作为辅助信息显示。每行粘贴一个公众号文章链接；提交后立即创建异步任务，后台逐条抓取并持续保存进度。抓取完成后以三列自适应手机比例窗口逐篇查看统一阅读模式和自动清理结果，不再在手机窗口外重复显示状态和 URL。必要时可恢复被识别的尾部，或使用右下角圆形按钮编辑、移除当前条目；失败窗口还可单独重新抓取该 URL，重试沿用当前批次，不会覆盖其他成功文章或管理员尚未确认导入的编辑内容。
- 每次重新选择文件或文件夹，都会替换当前整批预览，不会追加到旧预览。
- 解析后先在预览中检查和修改内容，再点击“确认导入”。有错误的条目不能提交。
- 每批最多导入 200 条内容；超过时请分批选择来源。
- 确认期间会锁定类型切换、文件选择、预览编辑和返回操作。上传失败的图片可以单独重试或从预览条目移除。
- 批量导入成功或失败只在当前导入页提示结果，不自动切换到内容管理，也不主动刷新内容列表；普通内容重新选择下一批文件即可继续，公众号文章发布成功后会清空当前链接和预览并继续停留在文章导入面板。

“新增”用于创建单条内容；它与批量导入都只追加新内容，不会保存或覆盖当前编辑器内无关的数据。文章新增、已发布文章编辑和导入草稿编辑复用同一个双栏弹窗：左侧编辑两行标题与 Markdown 正文，右侧修改封面和发布时间并实时查看阅读卡片。文章封面上传仅接受 JPG/JPEG、PNG、WebP；GIF 不可作为封面。标签默认值为“默认”，仅用于后台分类，小程序端不显示。

## 导入格式

| 内容类型 | 选择来源 | 解析规则 | 图片规则 |
|---|---|---|---|
| 私密文案 | 一份 TXT 文件 | 用空行、序号或 `---` 分隔多条文案 | 无 |
| 私密音频 | 多个 MP3/M4A 文件 | 每个文件独立成为一条音频，不要求填写标题 | 无 |
| 心笺 | 一份 TXT 文件 | 用空行、序号或 `---` 分隔多条内容 | 无 |
| 私密图册 | 一个图片文件夹 | 可识别不同子目录内的图片，或用相同名称加序号作为分组标识；未分组的单张图片各自成为一个图册 | 每组保留前 1–9 张 |
| 文章 | 每行一个公众号 URL | 仅支持 `mp.weixin.qq.com`；自动提取标题、正文、发布时间和封面；正文统一转换为 Markdown 阅读模式 | 正文图片从页面引用地址转存到项目 COS，封面登记为图片素材；手工编辑时选择本地图片会直传 COS 并自动绑定封面 |

私密图册和普通图片支持 JPG、JPEG、PNG、WebP、GIF，单张不得超过 5MB；文章编辑弹窗上传的封面仅支持 JPG、JPEG、PNG、WebP。超过每组图片数量上限时，按文件名排序保留前面的图片，不作为导入错误。

音频仅支持 MP3、M4A，单文件不得超过 50MB。浏览器选择文件后保留原始文件名；文件先上传到服务端临时目录，经 FFmpeg 根据每条音频自身的响度自适应标准化后写入 COS。处理成功、失败或中断后都会删除服务器临时文件；COS 只保留标准化后的播放文件。服务端在确认时保存原始文件名、对象 key、MIME 类型、处理后大小、时长和 `audioUrl`。小程序标题默认使用去除最后一个扩展名后的原始文件名，运营无需逐条填写标题。

内容管理的音频表提供“试听”入口。点击后在当前后台页面右下角显示悬浮播放器，沿用小程序完整音频卡片的视觉结构并缩小适配后台；支持播放/暂停、重播回到开头、拖动进度和时间显示，不提供循环、音量等高级功能。页面只维护一个播放器，初始不加载音频，首次点击时才使用 `Audio` 的 `preload="none"` 懒加载当前 `audioUrl`；切换另一条、刷新分页或删除当前条目会停止上一条播放。

TXT 优先按 UTF-8 读取，并兼容常见旧版中文 TXT 编码。当前导入不使用 Excel、粘贴表格或 ZIP。

## 预览与确认

- 绿色数量只在存在可导入条目时显示；有异常时单独显示需处理数量。
- 私密图册可修改标签，文本类可修改内容；公众号文章抓取成功后，预览区固定为三列等宽卡片并铺满可用宽度，阅读窗口保持接近小程序手机页面的纵横比，标题、元信息、内边距与工具按钮会随卡片宽度在受控范围内缩放，正文固定使用后台普通阅读字号。卡片正文区域仅允许纵向滚动，正文图片始终铺满内容宽度且不会撑宽卡片；正文基础间距为 `10px`，连续图片或媒体内部间距为 `12px`，两套参数独立控制以便单独微调。成功文章默认保留并随本轮确认导入，不设置复选框或单篇确认步骤。卡片右下角由上到下显示删除、编辑两个圆形按钮；编辑按钮打开与文章管理共用的双栏弹窗，可同时修改标题、Markdown 正文、封面和原始发布时间，右侧阅读卡片实时预览当前草稿。标题、封面和时间立即同步，正文停止输入约 300ms 后经服务端安全渲染更新；“保存”只更新本次导入草稿，最终仍需点击“确认导入”。关闭存在未保存修改的弹窗时必须确认放弃。删除按钮不弹确认，只从当前批次预览移除该条目，失败和重复条目也可直接移除，不影响已正式发布内容。系统识别到推广尾部时，会显示清理摘要和“恢复已移除文字”；恢复时按原文顺序放回文字，尾部图片不会恢复。完成整理后，点击导入预览卡片右上角“确认导入”，一次性把仍保留的全部成功文章写入内容池；全部成功文章被移除后，按钮自动隐藏且不能导入。
- 预览中的移除只影响本次导入批次。
- “确认导入”旁不拼接数量，数量独立显示。导入完成后，同一批次再次提交不会因重试重复追加相同 ID 的内容。

## 去重与素材复用

- 私密文案和心笺会先把正文首尾空白移除，并把连续空白折叠为一个空格，再直接比较正文；同一批次或当前内容池中已有相同正文时会跳过。
- 文章按规范化后的公众号来源 URL 哈希去重；重复文章会在导入结果中标记，确认发布时仍会再次去重。
- 私密图册不做内容项级去重；即使图片排列相同，只要内容 ID 不同，仍可分别导入。
- 批量上传、导入预检和文章抓取按原始文件字节的 SHA-256 与 `processingProfile` 共同识别素材。两者都相同才可复用素材 ID；同批相同图片只上传一次，并让各内容项引用同一素材。处理标记不同的图片不得互相复用派生图。后台单张上传当前不计算 SHA-256，因此不承诺跨历史去重。
- 音频不新增按文件内容的去重规则，继续使用现有内容 ID 和上传任务 ID 保证失败重试不会重复追加。

## 公众号文章导入边界

- 导入请求立即返回 `202` 和任务 ID，服务端逐条抓取并把进度写入 `article_import_jobs`；Admin 轮询状态。服务重启导致任务中断时，任务标记失败并要求重新创建，不伪装为继续执行。
- `author` 优先保存蓝色的公众号账号名称：先读取页面账号节点（如 `#js_name`、`.profile_nickname`），再读取脚本 `nickname` / `profile_nickname`；这些来源均为空时，才使用 `meta author` / `article:author`、可见作者署名或脚本 `author` 兜底。两者均缺失时保留空值，须在预览编辑中补充后才能确认导入；预览和保存沿用同一字段，手动编辑值优先。
- 页面 URL 只允许 `mp.weixin.qq.com`；正文图片允许来自任意公网图片主机，不再依赖微信图片域名白名单。图片请求仍会逐次校验协议、账号信息、标准端口、重定向和 DNS 解析结果；内网、回环、链路本地、组播等非公网地址一律拒绝，避免 SSRF 和 DNS 重绑定。
- 页面上限 8MB，单张图片上限 5MB，并校验超时、HTTP 状态、MIME 与图片文件魔数。公众号 `section/div` 会先还原为标题、段落、引用、列表、图片等语义块，再转换为统一 Markdown；字体、颜色、对齐、表格、视频、卡片、脚本、样式和事件处理器不进入正文。
- 自动清理只扫描正文最后 35% 且最多 60 个语义块。独立的推荐栏目标题、明确的点赞/在看/星标/留言/扫码关注指令、投稿商务联系方式、公众号内链密度等构成强信号；单个普通关键词、外部参考链接、路线/海拔/开支等正文数据不会触发。检测到连续正文恢复，或清理后不足 2 个正文块和 80 字时，会放弃自动删除。作者/编辑署名、来源、免责声明、版权和风险提示属于受保护内容，不会因为前面出现互动引导而连带删除；若同一段后半截附带投稿或商务联系方式，只移除联系后缀。
- 同一批文章完成抓取后，会额外检查每篇开头或结尾的边界语义块；只有带推广/互动/链接列表信号、且至少 3 篇相同的片段，才会作为“批次重复模板”移除。短文、只有 1–2 篇出现的片段和正文主题重复不会触发；移除内容仍可在预览中恢复，恢复时按原始正文顺序放回，批次移除的图片与尾部图片一样不恢复，只保留文字。
- 发布时间优先读取公众号页面的 `article:published_time`、`publish_time`、`create_time`、`ori_create_time`、`ct` 等字段（支持日期文本及 Unix 秒/毫秒时间戳），也读取页面可见发布时间。无法识别有效原始发布时间时，该篇标记为失败且不能确认导入，不使用抓取或导入时刻冒充原始发布时间。
- 正文图片按 SHA-256 转存到项目 COS 的文章目录，正文改写为项目 HTTPS 地址；封面按“哈希 + 处理标记”复用或登记图片素材。普通静态正文图和文章封面使用 `display-v1`，GIF/动画图以及高度超过宽度 3 倍的正文长图使用 `original-only`；文章封面绝不按文章大卡的 `2.35:1` 容器比例裁切。图片处理规则以服务端图片模块和相关测试为准。最长边不超过 96px 的静态小图继续过滤；仅正文首尾连续边界块中的极端横幅/竖条图片会按比例过滤，图片所在块允许带不超过 40 字的短标题或署名（短边不超过 160px、长边至少 400px、宽高比至少 5:1）。边界还支持“推荐阅读/往期/更多/相关阅读”等营销语义短标题与极端比例图片交错排列的推荐卡片，标题在图片前后均可、连续多组会成对移除；中间图片、普通图注或带较长正文的图片块不按比例过滤。单张正文图片转存失败时只移除该图片并显示警告，封面转存失败时文章继续导入但不显示封面。被自动清理的尾部图片不上传 COS，管理员恢复文字时按原始交错顺序恢复，图片仍不恢复。整篇文章抓取或正文转换失败才会将该条标记失败，不影响同批其他文章。
- `bodyMarkdown` 是文章正文的唯一保存字段。服务端按需将 Markdown 派生为安全 HTML，小程序再次清理后交给 `rich-text` 展示；HTTPS 链接保留，非 HTTPS 或危险协议不带跳转地址。不保存并行的 `bodyHtml` 或 `previewHtml`。后台编辑器支持标题、段落、加粗、斜体、删除线、引用、列表、链接、图片、分隔线、行内代码和围栏代码，不支持自定义 HTML。
- Admin 不在浏览器会话中保存或恢复文章导入任务 ID；退出文章导入页后再次进入，链接和预览均为空白。当前页面内查询失败时，“重试查询”继续查询本轮任务，不会重复创建。任务发布成功后立即删除，未发布的失败或中断任务最长保留 24 小时。服务启动时先清理一次，之后每小时主动清理，不依赖管理员再次访问。
- 导入正文图继续使用现有 `image_assets` 记录生命周期，文章仅额外保存 `bodyImageAssetIds` 引用元数据，正文内容仍只有 `bodyMarkdown` 一个真源。确认导入时从当前预览移除或重复的条目、过期任务、文章删除以及正文编辑后移除的图片都会进入现有 COS 回收流程；其他文章或尚未结束的导入任务仍引用同一对象时不会误删。COS 删除失败时保留素材登记，后续定时清理可重试。
- 本功能不授予转载许可。运营只能导入自有版权或已获授权内容，并负责保留必要署名、出处和来源 URL；不得用本工具绕过公众号访问控制或批量搬运无授权内容。

## 上传实现要点

- 普通本地图片和文章编辑弹窗的手工封面由浏览器直传 COS，服务端负责签名、请求 COS 生成派生图、确认可读后登记素材和保存内容引用；每组最多 3 路并发，底层按每组最多 100 张依次准备和登记。公众号文章的正文图和封面则由服务端先从来源地址校验、下载，再转存到 COS。
- 单条新增和批量导入都会校验图片素材是否已登记；批量导入与文章抓取按 SHA-256 加 `processingProfile` 复用，单张上传不做哈希去重。
- 批量内容 ID 在预览时固定，单条新增也沿用已成功上传的素材；网络中断重试不会重复追加内容。
- 音频按顺序经服务端 FFmpeg 处理后写入 COS，不参与图片处理；上传完成即可加入内容池，是否投放由小程序的“允许音频”开关控制。

## 维护速查

| 接口 | 用途 |
|---|---|
| `POST /api/admin/content/import/preflight` | 导入前检查重复正文，并查询可复用的历史图片素材 |
| `POST /api/admin/content/items` | 追加单条或一批普通内容；按内容 ID 幂等，并对私密文案和心笺正文执行最终去重 |
| `POST /api/admin/images/upload/prepare-batch` | 为新图片生成 COS 直传任务；按 SHA-256 加处理标记复用历史素材，并合并同批相同图片 |
| `POST /api/admin/images/upload/complete-batch` | 集中登记已成功直传的图片素材 |
| `POST /api/admin/audios/upload` | 接收单条 MP3/M4A、统一响度后上传 COS，并返回可加入内容池的条目 |
| `POST /api/admin/articles/import` | 创建公众号文章抓取任务并立即返回 `202` 与任务 ID |
| `GET /api/admin/articles/import/:jobId` | 查询文章导入任务及预览数据 |
| `POST /api/admin/articles/import/:jobId/publish` | 仅对 `ready` 任务按 `selectedIds` 发布当前预览仍保留且不重复的文章；`restoreTailIds` 指定需要恢复自动清理尾部的文章，`editedItems` 严格携带文章 ID、标题、Markdown 正文、封面和发布时间（服务端逐条校验任务归属及素材） |
| `POST /api/admin/images/reclaim` | 回收本次编辑中新上传、但取消或替换后不再引用的临时封面；仍被内容或导入任务引用时只保留，不误删 COS 对象 |

普通内容导入实现位于 `../server/admin/src/import.js`；文章管理和异步抓取位于 `../server/admin/src/article-manager.js`、`../server/src/modules/content/article-import.service.js` 和 `../server/src/routes.js`。改动导入流程后至少执行：

```powershell
cd admin\server
npm test
npm run verify:miniapp
```
