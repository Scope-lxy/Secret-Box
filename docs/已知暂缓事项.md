# 已知暂缓事项

状态：当前有效；2026-09-12 按源码核对实现边界，保留原有产品决定。

本文记录产品负责人已明确接受风险、暂不纳入当前开发与上线阻塞项的事项。后续代码审查、上线检查和需求讨论不得将以下事项重复列为待办或阻塞项；只有产品负责人明确变更决定后，才重新评估。

## 1. Admin 首次初始化密码

- 开发/测试环境在缺少密码时允许初始化 `admin / 123456`；生产类环境缺少已保存认证状态时不启用默认密码，认证状态损坏时拒绝加载。
- 产品负责人明确决定：当前不修改该机制，不增加强制改密、随机初始密码或额外初始化流程。
- 审查边界：不再将此项作为当前版本缺陷、上线阻塞或重复提醒事项。
- 重新评估触发条件：产品负责人主动要求调整后台登录策略。

## 2. 图片安全检查

- 当前后台的“图片安全检查”仅保留界面占位和展示样式，未接入实际图片审核逻辑。
- 产品负责人明确决定：当前不补充图片审核、图片内容识别或相关的自动拦截流程。
- 审查边界：不再将此项作为当前版本缺陷、上线阻塞或重复提醒事项。
- 重新评估触发条件：产品负责人决定启用图片审核能力，或平台审核要求发生变化。

## 3. 订阅消息

- 当前版本不提供订阅消息能力：后台不展示订阅设置、不保存模板或发送规则，服务端不记录授权、不调用微信发送接口，也不运行每日提醒定时任务。
- 小程序已经设计好的订阅页面、授权调用和页面视觉代码保留在源码中，但首页和设置页入口固定隐藏，不会触发授权弹窗。
- 产品负责人明确决定：由于“轻读手记”的新增内容、每日打卡提醒不适合依赖一次性订阅，且长期订阅模板由微信按小程序类目和模板类型决定，当前不将其作为上线能力。
- 审查边界：不再将订阅消息模板、定时提醒、授权测试列为当前版本上线阻塞项。
- 重新评估触发条件：微信公众平台实际为该小程序提供适配业务场景的长期订阅模板，或产品负责人明确要求恢复一次性订阅场景。

## 4. 用户自助自动注销

- 当前版本保留小程序内“注销账号”入口，使用标准按钮样式；点击后提示用户向当前小程序在 Admin 配置的开发者邮箱发送注销申请，并注明需要注销的小程序名称和对应的账号信息。
- 不提供用户自助提交、取消或 7 天后自动删除机制；开发者收到申请并核实后，在 Admin 的用户管理页面手动注销当前小程序账号。
- 多小程序账号注销按两份 PRD 的数据范围归属规则执行：删除当前小程序专属数据；共享范围仍由该账号的其他小程序持有时保留，当前小程序是最后归属时删除该账号在该共享范围中的数据；其他账号及该账号仍归属其他小程序的数据不受影响。
- 审查边界：不再要求恢复 7 天自动注销定时任务，也不把缺少自助注销 API 视为上线阻塞。
- 重新评估触发条件：微信审核明确要求当前类目提供小程序内自动注销，或产品负责人要求恢复自助流程。

## 5. 异机备份

- 项目规则不启用生产自动备份；线上是否存在额外计划任务未在本次核对中检查；仓库保留手动备份命令，但生产未启用定时调用，也不授权 Agent 在日常发布时自行运行。真正恢复仍须明确授权并确认有效恢复来源。
- 产品负责人明确接受当前无自动备份、无异机备份的边界，不将备份能力纳入本次首发工作。
- 审查边界：不再将缺少自动备份或异机备份作为当前版本缺陷、上线阻塞或重复提醒事项。
- 重新评估触发条件：正式业务量或营收明显增长、准备迁移服务器，或产品负责人主动要求提高灾备等级。

## 6. 生产环境文本安全检测开关

- 当前源码默认启用文本安全检测，但仍允许后台关闭。线上实际开关值未在本次文档核对中读取。
- 产品负责人明确决定：当前不将“生产环境可关闭文本安全检测”的配置能力改为强制锁定，也不将其作为当前版本上线阻塞项。
- 审查边界：不再把开关本身重复列为待办或阻塞项；若检测服务、开关配置或审核结果在真实运行中导致违规内容被放行、合法内容被错误拦截或用户操作失败，仍须按运行故障处理。
- 重新评估触发条件：产品负责人要求锁定生产配置，微信平台审核要求发生变化，或发生与文本审核相关的线上事故。

## 7. 激励广告绕过与不可用时放行

- 激励广告按微信小程序官方 `wx.createRewardedVideoAd` 流程处理：仅 `onClose` 回调明确返回 `isEnded: true` 时视为完整观看，提前关闭不继续执行受广告保护的动作；加载、展示或播放失败是否继续，按下条“无广告时视为看完”配置决定。
- 广告不可用、无库存或弱网时仍按广告位“无广告时视为看完”配置保留放行体验；未配置有效广告位时也继续沿用现有放行语义。
- 微信小程序没有向服务端提供可独立核验的激励广告完成回调，因此完成信号由客户端广告回调触发；服务端不额外引入挑战、完成凭据或一次性解锁令牌。
- 广告位 ID 配置错误、广告在正常可播放时被异常跳过、放行率异常或其他导致正常用户体验、广告展示或统计失真的真实故障，仍须正常处理。

## 使用规则

- 本文只豁免上述七项，不豁免其他问题；尤其不豁免广告位配置、正常播放链路异常、放行率异常，以及手记与打卡的重复提交保护等独立问题。
- 任何涉及这些事项的真实运行故障仍应正常处理；本记录只说明当前不扩展对应机制。
